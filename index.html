Under Review | Deep Learning Indaba 2026

CASL-TransSLR: Central African Sign Language Recognition

Developed a privacy-preserving transformer pipeline using pose-only representations, 225-D kinematic features, and signer-independent evaluation across 19 participants.

  • 80.39% signer-independent accuracy
  • 99MB model footprint for constrained devices
  • PyTorch, MediaPipe, W&B, Scikit-learn
  • View the Hugging Face model
Under Review | Interspeech 2026

Distilling Intelligence from Noise

Built a synthetic data generation and distillation pipeline for low-resource Kinyarwanda speech technologies using a 51-hour Kinya-Synth-50h corpus.

  • Fine-tuned a 1B-parameter audio language model
  • 19.2% WER on human-held-out testing
  • Gemini 2.5 Flash, OuteTTS, Whisper Large V3
